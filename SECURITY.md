# Security policy

## Scope and expectations

RentnerProxy Marketplace is an early public preview. The public catalog and registration are still in preparation. Security-sensitive components include authentication and initial administrator setup, authorization, file storage, backups and recovery, the Rust core, and the bundled appliance runtime.

Report a suspected issue with the tested version, image digest or commit, affected component, reproduction steps, impact, and any suggested mitigation. Remove unrelated personal data and live credentials. Revoke or rotate any exposed credential immediately. Checks in this repository do not constitute an independent security certification or a guarantee that every vulnerability has been found.

## Reporting a vulnerability privately

Do not disclose vulnerabilities, exploit details, credentials, or affected private data in public issues or pull requests.

Use the [Marketplace private security advisory form](https://github.com/RentnerProxy/marketplace/security/advisories/new). GitHub private vulnerability reporting is enabled for this repository, so the report can be discussed with maintainers and invited collaborators without public disclosure.

If the form is unavailable, keep the report private. Ask [@RentnerKev](https://github.com/RentnerKev) for a private contact method without posting vulnerability details, or use an existing private conversation with the maintainer. The project does not publish a dedicated private security email address. Do not open a public vulnerability issue as a fallback.

The maintainer coordinates validation, remediation, and disclosure. No response-time or fix-time guarantee is currently published. Do not test against someone else's deployment without permission.
